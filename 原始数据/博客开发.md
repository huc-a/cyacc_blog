# 三、技术选型
## 1. 选型

| 层次      | 推荐选择                            | 在这个项目里的职责              |
| ------- | ------------------------------- | ---------------------- |
| 前台与后台页面 | Nuxt＋Vue＋TypeScript             | 复用设计变量、组件、接口类型和页面逻辑    |
| 后台 UI   | Naive UI＋自定义 CSS                | 表格、表单、弹窗、抽屉、日期选择等      |
| 业务接口    | Spring Boot                     | 内容管理、发布、媒体、外观配置、统计聚合接口 |
| 认证授权    | Spring Security                 | 管理员登录、接口权限、会话管理        |
| 数据持久化   | PostgreSQL＋MyBatis              | 保存内容、教程章节、设置和操作记录      |
| 数据库迁移   | Flyway                          | 用版本化脚本管理表结构变更          |
| 编辑器     | Markdown 为主，先验证 TOAST UI Editor | 内容录入与阅读预览              |
| 图表      | Apache ECharts                  | 趋势、来源、设备、排行、热力图        |
| 访问采集    | Umami                           | 收集访问事件，提供统计数据          |
| 图片与附件   | 开发期本地目录，上线按需要接对象存储              | 不把上传图片继续保存在浏览器里        |

# 四、后前端开发
## 1. 后端模块设计
- SpringBoot内部划分按 业务分模块，不按页面堆接口
	|模块|主要职责|
	|---|---|
	|`auth`|管理员登录、退出、会话和权限|
	|`content`|公共内容字段、草稿、发布、下线、回收站|
	|`article`|文章正文与文章专属逻辑|
	|`work`|项目截图、技术栈、演示与源码地址|
	|`tutorial`|教程系列、章节、排序与发布|
	|`website`|网站收藏、分类、链接状态|
	|`deal`|优惠信息、有效期、核验状态|
	|`media`|上传校验、文件保存、媒体引用|
	|`site`|站点信息、首页模块、主题与导航配置|
	|`analytics`|调用统计服务、统一指标、生成报表|
	|`system`|操作日志、数据导出和运维相关能力|
## 2. 前端模块设计
	 采用不同渲染策略
- 前台内容页：服务端渲染，逐步增加缓存。
- 后台页面：客户端交互为主。
- 很少变化的说明页：可以预渲染。
## 3.接口设计
- 建议接口路径先统一：
```
/api/public/...
    公开内容：文章、教程、作品、网站、羊毛、站点配置

/api/admin/...
    管理操作：新增、编辑、发布、上传、设置、报表

/api/auth/...
    登录、退出、当前账号
```
- 比如：
```
GET    /api/public/articles
GET    /api/public/articles/{slug}

GET    /api/admin/articles
POST   /api/admin/articles
PUT    /api/admin/articles/{id}
POST   /api/admin/articles/{id}/publish

POST   /api/admin/media
PUT    /api/admin/site/appearance

GET    /api/admin/analytics/overview
GET    /api/admin/analytics/trend
GET    /api/admin/analytics/top-content
```

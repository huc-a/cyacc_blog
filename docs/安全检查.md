## 应用验证

- PostgreSQL 测试覆盖草稿隔离、冻结保护、事务回滚、并发冲突、错误指针、回收/恢复。
- 管理接口要求会话与 CSRF；退出/改密码使会话失效。登录每来源每分钟最多 10 次；生产 Nginx 另有限流。
- Markdown 禁用 HTML/危险协议，前后台共用渲染器，浏览器验证不执行注入脚本。
- 上传只接受可解码 PNG/JPEG，5 MB 与像素限制，随机文件名、重新编码。草稿媒体不公开，历史引用阻止删除。
- 站点字段白名单、MyBatis 参数绑定；不抓取外部链接；Umami 凭据仅服务端读取。
- 生产角色实测：迁移成功；运行账号 CRUD/identity 序列可用；CREATE/ALTER 被拒绝，无超级用户/创建库/角色权限。

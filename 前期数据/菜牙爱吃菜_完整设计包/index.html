DESIGN NOTES / 设计手记

给想法一个安静的地方：
我的个人博客设计笔记

林间 · 示例作者2026.10.21设计 / 随笔

一个好的博客，不一定拥有最多的功能。它可以只是一个打开之后，愿意坐下来读几段文字的地方。

阅读设置

01 / 从一篇文章开始

最初想做个人博客，是因为很多想法散落在不同的地方：读到一半的书、项目中的小发现，以及走在路上突然想到的一句话。我想把它们收集起来，放在一个不那么匆忙的地方。

这一次，我决定先不考虑复杂的动效，也不急着把首页填满。先写好一篇文章，让标题、段落和留白各自找到合适的位置，再慢慢搭建其余的部分。

让风景留在文字背后，让重要的想法有空间被看见。

02 / 让文字拥有自己的节奏

暖纸色的衬线正文，像一本随手翻开的书。背景中的山脊、薄雾与湖面并不急着讲述什么，它们只是安静地留在卡片边缘，让每一次停顿都有一个可以落脚的地方。

首页可以更通透一些，让风景参与画面；进入长文之后，纸面的底色会变厚。依然能感受到窗外的颜色，却不必在每一行文字之间辨认山峦的轮廓。

  • 标题负责带路，不需要每一个都大声说话。
  • 段落之间留出呼吸的距离，但不要打断意思。
  • 强调色只用在需要注意的位置，例如文章链接与关键入口。
试读时可以先关闭调色盘，读完这两段；再打开面板调整正文不透明度。背景越复杂，越需要认真检查文字是否清晰，而不是只看磨砂是否漂亮。

03 / 把设计变成可以维护的系统

选定方向之后，我会把颜色、宽度和间距整理为设计变量。例如通过 --paper 管理正文底色，用 --glass 管理导航与卡片，再通过 --blur 控制磨砂程度。

CSS / Glass surface
.glass {
  background: rgba(250, 247, 235, 0.66);
  backdrop-filter: blur(18px);
  border: 1px solid rgba(255, 249, 236, 0.61);
}

.article-paper {
  background: rgba(252, 249, 240, 0.88);
}

这些是本次原型的起始参数，不是通用标准。替换背景之后，应重新检查最亮和最暗的位置，确认文章仍然读起来轻松。

区域视觉任务设计方式
全站背景形成统一氛围固定山景，保留完整画面
导航与卡片呈现空间层次暖色半透明、细高光边框
文章正文维持连续阅读更厚的纸色、衬线正文、大留白

04 / 留下一些空白

博客不需要在第一天就看起来很热闹。只有两篇文章，就认真呈现这两篇；还没有完整作品，就先写下正在做的事情。比起装饰出丰富，更重要的是让内容本身值得停留。

以后也许会增加摄影、书单和旅行记录，但它们会沿用同一套文字与颜色规则。页面可以慢慢长大，气质不必每次重新开始。

THE END / 谢谢阅读

风景在文字背后，阅读始终在画面中央。这是示例文章，不代表真实作者经历。
